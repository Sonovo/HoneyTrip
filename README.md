# HoneyTrip

Simple mobile-first travel currency converter.

## Currencies

- GBP - UK Pound
- USD - US Dollar
- AMD - Armenian Dram
- TOMAN - Iranian Toman

## How to test

Open `index.html` in Safari or Chrome.

## How to update rates

Open `script.js` and update:

```js
const ratesToGBP = {
  GBP: 1,
  USD: 1.33,
  AMD: 510,
  TOMAN: 110000
};
```

## How to host free

Upload this folder to GitHub, then connect it to Vercel.
